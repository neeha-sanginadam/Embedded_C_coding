Goal:
Do not memorize solutions.

For every problem:
    1. Understand the problem
    2. Design the algorithm
    3. Write C code from scratch
    4. Compile and test
    5. Test edge cases
    6. Explain the code verbally
    7. Analyze time and space complexity
    8. Identify possible bugs / undefined behavior
