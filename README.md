# Embedded C Interview Coding Roadmap

A structured coding roadmap for preparing for **Embedded Software / Firmware / Embedded C interviews**.

The focus is on:

* C programming
* Pointers and memory
* Bit manipulation
* Arrays and strings
* Structures and unions
* Linked lists
* Stack and queue
* Function pointers
* Embedded C
* OS-related coding
* Debugging and output-based questions

# 20. Practice Rules

For every coding problem:

1. [ ] Understand the problem
2. [ ] Think about the algorithm
3. [ ] Write the solution without looking up code
4. [ ] Compile it
5. [ ] Test normal input
6. [ ] Test edge cases
7. [ ] Check for memory issues
8. [ ] Check for undefined behavior
9. [ ] Explain the solution verbally
10. [ ] Analyze time complexity
11. [ ] Analyze space complexity
12. [ ] Try to implement it again later without reference

# Target

The goal is **not to memorize 380 solutions**.

The goal is to reach the point where I can:

* Understand a new C problem quickly
* Design the solution myself
* Write the code without assistance
* Handle pointers confidently
* Reason about memory
* Identify edge cases
* Debug my own code
* Explain my solution during an interview
* Write embedded-oriented C code comfortably

**Primary focus: C + Pointers + Bit Manipulation + Linked Lists + Embedded C + Debugging.**
